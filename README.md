# EXODUS Teaching with Ms. Tee™

A modern, high-performance responsive website for **EXODUS Teaching with Ms. Tee** — a premier cosmetology training and State Board preparation academy.

## 🌟 Features

- **Hero Section**: Modern typography, golden halo effect, official branding, and call-to-action buttons.
- **Key Statistics Counter Bar**: Highlighted metrics (pass rates, batches, hands-on salon hours).
- **Meet Ms. Tee**: 3-column interactive layout detailing Ms. Tee's background, credentials, and teaching philosophy.
- **Course Programs**: 5 detailed cosmetology courses with HD graphics and curriculum breakdown.
- **Why Choose EXODUS**: Interactive 6-benefit card grid and visual journey.
- **Training Process**: 5-step roadmap from enrollment to getting licensed and launching a career.
- **Student Success Stories**: Testimonials, ratings, and graduate success highlights.
- **Student Work & Gallery**: Interactive multi-category filter gallery (Haircut, Color, Nail Care, Skin & Facials, Makeup).
- **CTA Banner**: Dynamic banner with hands-on tools, feature badges, and booking triggers.
- **Interactive Booking Modal**: Real-time form with course selection, schedule preference, and confirmation.
- **Comprehensive Footer**: Quick links, full course directory, contact info, social links, and email subscription.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Build for Production

```bash
npm run build
npm start
```
